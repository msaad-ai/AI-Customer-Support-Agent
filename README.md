# 🤖 AI Support Agent

An AI-powered *Customer Support Agent* that helps users with Refund / Billing queries.  
Built with *OpenAI Agents SDK* + *Chainlit UI*.

## ✨ What it does
- Understands customer questions
- Runs support workflows
- Responds like a real agent
- Specially focused on: Refund & Billing support

## 🧠 Tech Stack
| Technology | Purpose |
|-----------|---------|
| OpenAI Agents SDK | AI Reasoning / Actions |
| Chainlit | Chat UI |
| Python | Project Core |

## 🚀 How to Run
1) Create .env  
   → Add your OpenAI API key inside it  
2) Install dependencies  
3) Run Chainlit app

> .env is private & already ignored via .gitignore ✅
